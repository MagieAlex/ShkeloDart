# ShkeloDart 🎯

Ein leichtgewichtiges Dart-Turnier-Tool mit grafischer Oberfläche (GUI), entwickelt in Python mit Tkinter.  
Ermöglicht das Eintragen beliebig vieler Spieler, automatisierte Paarungen, die Auswahl von Siegern und die Anzeige eines finalen Scoreboards.

---

## ✨ Funktionen

- Spieler*innen hinzufügen
- Zufällige 1-vs-1-Paarungen erstellen
- Gewinner nach jedem Match wählen
- Siege werden gezählt (kein Unentschieden)
- Übersichtlicher Endstand nach allen Spielen

---

## 🖥️ Voraussetzungen

- Python 3.x  
- Kein zusätzliches Setup nötig (Tkinter ist standardmäßig enthalten)

---
